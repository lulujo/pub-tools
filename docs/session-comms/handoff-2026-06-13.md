### Markdown&rarr;Gutenberg converter gotchas (hit this session)
Source files use straight quotes + Unicode em dash only. The smart-quote/entity converter needed two fixes that will recur:
1. **Nested bold+italic:** a `**bold question**` containing `*italic*` (e.g. Annie&rsquo;s *Gray Lady* / *What-Ifs&hellip;*) breaks a `\*\*([^*]+)\*\*` bold regex. Use non-greedy `\*\*(.+?)\*\*`.
2. **Opening quote after `*` or em dash:** a `"` immediately preceded by `**` (e.g. `**"Comstock"`) or by an em dash (e.g. `justice—"something"`) was mis-rendered as a closing `&rdquo;`. Fix: run smart-quotes **before** em-dash conversion and include `*` and `—` in the opening-quote lookbehind set: `(^|[\s\(\[\{\*—])"`.

Verified final output: 0 stray asterisks, 0 misrendered quotes, 0 leaked image-meta lines across all three.
