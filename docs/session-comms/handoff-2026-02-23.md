## What This Session Did

### 1. Social Media Automation Research

Jamie asked about automating social posting when blog posts go live. Researched the full landscape: Buffer, IFTTT, Zapier, Jetpack Social, Blog2Social, Autoblue, and direct APIs (Bluesky AT Protocol, Facebook Graph API, LinkedIn API).

**Key findings:**
- **Buffer API is private** &mdash; not publicly accessible. Can&rsquo;t automate programmatically. Still works as manual dashboard or Zapier action target. Confirmed via live web data.
- **Autoblue** is a free, lightweight WP plugin for auto-posting to Bluesky. Custom message stored in `autoblue_custom_message` post meta with `show_in_rest: true`. Fires on publish including scheduled posts.
- **Jetpack Social** custom message field (`jetpack_publicize_message`) is REST API accessible. **Tested and confirmed** &mdash; created draft post 5541, set the field via REST API, read it back successfully, deleted test post.
- **Zapier free** covers 5 platforms (Bluesky, FB, LI, IG, Pinterest) with template-based messages, 100 tasks/month, unlimited zaps. Tami Veldura uses Zapier.
- **IFTTT Pro** is $2.99/mo but only template-based messages.

**Confirmed recommendation: Autoblue (free) + Jetpack Social Basic ($48/yr)**
- Bluesky: Autoblue, custom message via `autoblue_custom_message`, instant on publish
- FB/LI/IG/Pinterest: Jetpack Social Basic, custom message via `jetpack_publicize_message`, instant on publish
- Both fields writable via REST API &mdash; Rookwood can set custom social messages when creating posts
- Jamie writes personal-voice messages ahead of time, stored in post meta, auto-posted on publish day

**Jamie is still thinking about it.** She hasn&rsquo;t committed to this stack yet. Don&rsquo;t proceed with implementation until she confirms.

## Technical Notes

### REST API auth
The `.env` password has spaces (WordPress Application Password format). When using curl, **remove the spaces** from the password &mdash; the spaced format causes auth failures. MCP tools handle this automatically.

### Jetpack Social meta fields (confirmed accessible via REST API)
```
jetpack_publicize_message        (string) &mdash; custom social share message
jetpack_publicize_feature_enabled (boolean) &mdash; toggle sharing per post
jetpack_social_post_already_shared (boolean) &mdash; prevents re-sharing
jetpack_social_options           (object) &mdash; image generator settings
jetpack_publicize_connections    (array) &mdash; currently empty (no accounts connected)
```

### Autoblue meta fields (confirmed from source code)
```
autoblue_custom_message  (string, show_in_rest: true)
autoblue_enabled         (boolean, show_in_rest: true)
autoblue_shares          (object, show_in_rest: true)
autoblue_post_url        (string, show_in_rest: true)
```
