## Technical Notes

### REST API auth
The `.env` password has spaces (WordPress Application Password format). When using curl, **remove the spaces** &mdash; the spaced format causes auth failures. MCP tools handle this automatically.

### Inkwren MCP key facts
- API key is workspace-scoped (one key = one workspace)
- All 16 catalog tools are read-only (Write scope on key is for HTTP POST method, not write operations)
- `inkwren_` prefix applied by MCP server in `register-tools.ts`
- Production cutover: change `INKWREN_API_URL` and `INKWREN_AUTH_TOKEN` in `.env`
