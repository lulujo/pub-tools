## Technical Notes
- StoryBundle has **no JSON endpoint** (`<slug>.json` &rarr; HTTP 500); HTML parse is the only path.
- Each book has **two** `book_detail_link` anchors (cover + name), so a raw grep count double-counts; parse by `<li class="book">` instead (15 books, not 30, on /humor).
- Parser boundary uses `(?=<li class="book">|</ul>|\Z)` so the final book is captured even without a trailing `</ul>` (caught by an edge test).
- Re-capture discipline: if the parser ever returns 0 for a *live* bundle, the markup changed &mdash; re-save a fixture and adjust anchors (documented in README).
