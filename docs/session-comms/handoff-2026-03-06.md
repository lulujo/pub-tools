## Technical Notes

### Batch Image Upload via REST API
The WordPress MCP `create_media` only accepts URLs. For local file uploads, use direct REST API:
```bash
curl -s -X POST "https://blackbirdpublishing.com/wp-json/wp/v2/media" \
  -u "claude:$(echo $CLAUDE_BLACKBIRD_WP_PASSWORD | tr -d ' ')" \
  --header "Content-Disposition: attachment; filename=\"filename.jpg\"" \
  --header "Content-Type: image/jpeg" \
  --data-binary "@/path/to/file.jpg"
```
The JSON response contains control characters that break Python 3.9&rsquo;s `json.loads()`. Fix with:
```python
json.loads(response.replace('\t','\\t').replace('\n','\\n').replace('\r','\\r'))
```
